# 📸 Easy Instructions - 3 Steps Only!

## What You Need to Do

### Step 1: Save Screenshots (2 minutes)
From the chat above, **right-click each screenshot** and save to:
```
Desktop/app_screenshots/
```

You can name them anything (screenshot1.png, screenshot2.png, etc.)
The script will process them automatically!

### Step 2: Run Script (1 minute)
```bash
python auto_enhance_screenshots.py
```

### Step 3: Done! ✅
Check `Desktop/promo_final/` for your professional promotional images!

The script will:
