# 📸 How to Take Perfect App Screenshots

## Quick Guide

### Step 1: Take Screenshots from Your App

#### On Android Device:
1. **Open your Book Reader app**
2. **Navigate to each screen**
3. **Take screenshot:** Press **Power + Volume Down** simultaneously
4. **Screenshots saved to:** Gallery → Screenshots folder

### Step 2: Transfer to PC

#### Method 1: USB Cable (Fastest)
```
1. Connect phone to PC via USB
2. Enable "File Transfer" mode on phone
3. Open phone storage on PC
4. Navigate to: DCIM/Screenshots/ or Pictures/Screenshots/
5. Copy screenshots to: Desktop/app_screenshots/
```

#### Method 2: Cloud Storage
```
1. Upload screenshots to Google Drive/Dropbox
2. Download on PC
3. Save to: Desktop/app_screenshots/
```

#### Method 3: Email
```
1. Email screenshots to yourself
2. Download on PC
3. Save to: Desktop/app_screenshots/
```

### Step 3: Rename Screenshots

Save with these exact names in `Desktop/app_screenshots/`:

1. **home_screen.png** - Home screen showing book list
2. **pdf_reader.png** - PDF reading interface
3. **epub_reader.png** - EPUB reading screen
4. **bookmarks.png** - Bookmarks or progress screen
5. **settings.png** - Any additional feature screen (optional)

## 🎯 Screenshot Quality Tips

### Do's ✅
- ✅ Take in **portrait mode** (vertical)
- ✅ Use **good lighting** (bright screen)
- ✅ Show **actual content** (real books/documents)
- ✅ Keep screen **clean** (no notifications)
- ✅ Use **high resolution** (1080x1920 or higher)
- ✅ Show **key features** clearly
- ✅ Make sure **text is readable**

### Don'ts ❌
- ❌ Don't include personal information
- ❌ Don't show copyrighted content prominently
- ❌ Don't take blurry screenshots
- ❌ Don't include notification bar clutter
- ❌ Don't use landscape mode
- ❌ Don't show error messages
- ❌ Don't include test/dummy data

## 🔧 Troubleshooting

### Screenshot Not Saving
**Problem:** Screenshot button combination not working
**Solutions:**
- Try Power + Volume Down again
- Hold buttons for 1-2 seconds
- Check if screenshot sound played
- Look in Gallery → Screenshots

### Can't Find Screenshots
**Problem:** Screenshots not in expected folder
**Solutions:**
- Check Gallery app → Screenshots album
- Look in DCIM/Screenshots/
- Check Pictures/Screenshots/
- Search for recent images

### Screenshot Quality Poor
**Problem:** Screenshots look pixelated
**Solutions:**
- Increase screen brightness
- Clean screen before taking screenshot
- Use phone's native screenshot feature
- Don't zoom in before taking screenshot

### Transfer Issues
**Problem:** Can't transfer to PC
**Solutions:**
- Try different USB cable
- Enable File Transfer mode on phone
- Use cloud storage instead
- Email screenshots to yourself
